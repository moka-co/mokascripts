# Analyze Reel

This skill allows for the technical analysis of Instagram Reels using a specialized Python script.

## Workflow

1.  **Extract URL**: Identify the Instagram Reel URL provided by the user.
2.  **Execute Analysis**: Run the `analyze_reel.py` script with the provided URL as the first argument.
3.  **Output**: Provide the exact output generated by the script to the user.

## Instructions

-   Execute the following command to analyze the reel:
    ```powershell
    python3 python/analyze_reel/analyze_reel.py "<REEL_URL>"
    ```
-   **Ignore** all other files in the `python/analyze_reel/` directory unless specifically needed for debugging.
-   **Wait** for the script to complete its execution.
-   **Return** the output from the "ANALYSIS RESULT" section to the user exactly as it appears.
